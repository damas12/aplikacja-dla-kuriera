NAJPROSTSZY SPOSÓB, ŻEBY DOSTAĆ APK Z TEGO PROJEKTU

Opcja A — Android Studio:
1. Zainstaluj Android Studio na komputerze.
2. Rozpakuj KurierRadar_MVP_0.1.zip.
3. Otwórz folder KurierRadar w Android Studio.
4. Poczekaj na pobranie zależności.
5. Wybierz Build > Build APK(s).
6. Plik będzie w: app/build/outputs/apk/debug/app-debug.apk

Opcja B — GitHub (projekt ma już automatyczny builder):
1. Utwórz puste repozytorium GitHub.
2. Wrzuć zawartość folderu KurierRadar.
3. Otwórz zakładkę Actions > Build APK > Run workflow.
4. Po zakończeniu pobierz artifact „KurierRadar-debug-apk”.
5. W środku będzie app-debug.apk.

APK debug jest wystarczające do prywatnej instalacji na własnym telefonie.
